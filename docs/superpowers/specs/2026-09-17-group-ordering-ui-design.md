# 分组排序与界面优化设计

## 目标

让已认证用户无需进入拖拽排序模式，就能在每个分组标题处快速上移或下移分组；同时统一分组卡片、标题区和操作区的视觉层级。游客和只读访问者不显示编辑操作。

## 交互

- 分组卡片标题显示分组名称、站点数量和操作区。
- 编辑模式下，操作区新增“上移”和“下移”图标按钮；第一个分组禁用上移，最后一个分组禁用下移。
- 点击按钮后，前端立即交换相邻分组位置，再调用现有 `updateGroupOrder` 批量接口写入全部 `order_num`。
- 写入失败时重新获取分组数据，恢复服务端顺序，并通过已有错误提示呈现失败原因。
- 现有拖拽排序入口及保存流程保持不变，作为批量调整方式。
- 所有新增图标按钮提供中文 `aria-label`、tooltip 与 44px 触控目标。

## 组件与数据流

- `App.tsx` 新增一个分组相邻移动处理函数，负责边界校验、乐观更新、调用 API 与失败恢复。
- `GroupCard.tsx` 接收当前分组索引、总数与移动回调，只负责渲染操作按钮并将方向上报。
- 不修改 D1 schema、Worker 路由或 HTTP API；继续使用已有的 `updateGroupOrder`。

## 视觉方向

采用“高效管理优先”的克制优化：标题区采用更紧凑的名称、数量与操作分组，按钮使用低干扰的描边/悬停反馈。卡片维持现有主题令牌、圆角和毛玻璃兼容性，不引入新的字体、色彩体系或持续动画。

## 验证

- 执行 `pnpm lint` 与 `pnpm build`。
- 本地快速验证：上移、下移的边界禁用和调用顺序。
- 部署到 Cloudflare 后，在部署地址验证交换顺序、刷新后的持久化、游客无编辑操作及移动端可用性。
