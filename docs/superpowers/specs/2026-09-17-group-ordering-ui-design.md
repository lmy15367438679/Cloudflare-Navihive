# 分组拖拽与导航界面统一设计

## 目标

让已认证用户直接从分组标题处拖动分组，取消上下移动按钮和独立的分组排序界面；同时将界面收敛为成熟、克制、信息层级清晰的工具型导航网站。游客和只读访问者不显示编辑操作。

## 分组排序交互

- 分组标题左侧提供独立拖拽手柄，卡片其他区域继续承担折叠、编辑和站点操作，不触发分组拖拽。
- 桌面端仅在标题区悬停或键盘聚焦时显示手柄；触屏设备在编辑模式下以低对比度常驻，避免没有 hover 时无法发现操作。
- 键盘用户可以聚焦手柄并通过 DnD Kit 的键盘传感器完成移动；手柄提供明确的中文无障碍标签。
- 拖拽结束后前端立即应用新顺序，并通过已有 `updateGroupOrder` 接口保存完整的 `order_num` 列表。
- 保存失败时恢复拖拽前顺序、静默重新获取服务端数据并显示错误提示。
- 保存期间使用同步锁阻止重复提交，拖拽手柄进入不可操作状态。

## 代码结构

- `App.tsx` 保留一个分组排序上下文和一个排序持久化入口，负责乐观更新、同步锁、API 调用与失败恢复。
- `GroupCard.tsx` 自身接入 `useSortable`，仅把 listeners 绑定到标题手柄；常规内容和站点卡片不承担分组拖拽事件。
- 删除上下移动 props、位置索引 Map、箭头按钮、旧 `SortableGroupItem` 组件和 `GroupSort` 专用渲染分支。
- 站点拖拽排序保持独立，避免与分组拖拽传感器或 ID 命名冲突。
- 不修改 D1 schema、Worker 路由或 HTTP API。

## 视觉方向

采用成熟工具型导航风格：减少毛玻璃和大面积阴影的视觉权重，通过清晰的背景层级、细边框、统一圆角、紧凑标题区和稳定间距建立秩序感。绿色继续作为品牌强调色，仅用于选中、焦点和主要操作。

- 分组卡片：低阴影或无阴影，悬停主要改变边框和背景，不产生明显漂浮。
- 标题区：名称、数量和操作形成明确层级；次要操作保持低对比度，聚焦或悬停时增强。
- 站点卡片：统一图标尺寸、文字行高、最小高度和状态反馈，减少装饰性变化。
- 侧栏与顶部栏：使用相同表面色、边框、控件高度和选中态，避免不同区域像来自不同设计系统。
- 深浅主题继续由现有语义令牌驱动；不引入新的硬编码色板或持续动画。

## 逻辑审查范围

- 检查分组与站点排序的 ID、边界、并发锁和失败回滚。
- 合并重复渲染参数与排序保存逻辑，删除不再使用的状态、枚举、导入和组件。
- 保持虚拟化只读列表、单分组视图、游客模式及折叠状态兼容。
- 不进行与排序和视觉统一无关的业务重构。

## 验证与发布

- 执行 Prettier、ESLint 和生产构建。
- 验证鼠标手柄拖拽、键盘拖拽、触屏手柄可见性、保存失败回滚和刷新后顺序持久化。
- 验证游客无编辑操作、站点内部排序无回归、深浅主题和常见响应式宽度。
- 完成代码审阅后推送 `main`，跟踪 GitHub Actions 和 Cloudflare Worker 部署结果。
